# Game builds and prototypes

- [The Open Wild](open-wild/) is the four-chapter 3D game. Its browser assets are in `open-wild/public/`.
- [Early Canvas prototype](prototypes/early-canvas/index.html) is the original single-file experiment. Open the file locally to try it.
- [Missed This Stop](../missed-this-stop/) is the separate hand-tracking build. Cloudflare Pages builds from that directory.

Start with the [repository README](../README.md) for public links and local setup.
